# Shri-Hit-Premanandji-Maharaj--Ekantik-QA-Extraction

Extract question and answers from the videos of Shri Hit Premanand ji Maharaj into a CSV dataset.

## Process

The extraction process involves several automated steps to transform YouTube video content into a structured Q&A dataset. Here's what happens at each stage:

1. **Video Extraction**: 
   - Use `yt-dlp` (a YouTube downloader tool) to fetch metadata for each video without downloading the full video file.
   - Retrieve video chapters (which serve as question titles with start/end timestamps) and automatic captions generated by YouTube in both Hindi and English.
   - Captions are downloaded in XML format (SRV1 or VTT) containing text segments with precise timestamps.

2. **Caption Parsing**: 
   - Parse the downloaded XML caption files using BeautifulSoup (a Python library for HTML/XML parsing).
   - Extract individual text segments along with their start and duration timestamps from the structured XML.
   - Handle both Hindi and English caption streams separately to maintain language distinction.

3. **Q&A Extraction**: 
   - For each video chapter (treated as a question), identify the start time.
   - Collect all caption text segments that occur within a 20-second window before and after the chapter start time.
   - This time-buffering approach ensures the "answer" captures the relevant discussion around each question.
   - Process both Hindi and English captions to create bilingual answers.

4. **Data Structuring**: 
   - Organize the extracted data into a standardized dictionary format for each Q&A pair.
   - Include fields like: video_id (YouTube video identifier), question_number (sequential order), start_time/end_time (chapter timestamps), question (chapter title), answer_hindi (concatenated Hindi captions), answer_english (concatenated English captions).

5. **CSV Export**: 
   - Use pandas (a Python data analysis library) to convert the list of Q&A dictionaries into a CSV file.
   - The resulting CSV contains one row per Q&A pair, making it easy to analyze, share, and use in other applications.
